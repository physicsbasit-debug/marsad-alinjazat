# مرصد الإنجازات v0.12.0

**مرصد الإنجازات** منصة عربية RTL لإدارة أعمال المادة وبناء ذاكرة مؤسسية للمعلم الأول ورئيس المجال. الفكرة ليست جمع ملفات في شاشة واحدة، بل ربط الأشخاص والأعمال والقرارات والتخطيط والتحصيل والإشراف والفعاليات والوثائق في سجلات قابلة للمتابعة والتقرير.

## ما يعمل حاليًا

- لوحة قيادة تعتمد على البيانات الفعلية للأعمال التي تحتاج انتباهًا.
- ملفات مهنية للمعلمين وسيرة ذاتية منظمة.
- طلبات ملفات وروابط رفع خارجية مع مراجعة واعتماد.
- توثيق فعاليات بالأدلة والصور والمشاركين.
- اجتماعات وقرارات ومسؤوليات ومواعيد متابعة.
- تخطيط ومتابعة منهج ووحدات ونسب إنجاز وتأخر.
- إشراف فني وزيارات وإجراءات متابعة.
- تحصيل ونتائج وتدخلات علاجية وإثرائية.
- مكتبة وثائق مرتبطة بالسياق التربوي.
- Google Drive اختياري كمخزن فعلي للملفات عبر OAuth.
- GitHub Pages كمعاينة آمنة ببيانات نموذجية دون تزييف عمليات الحفظ.
- أرشيف تاريخي سنوي للقراءة فقط مع حزمة تسليم قابلة للطباعة.
- بحث شامل عربي من رأس التطبيق مع فلاتر للقسم والعام الدراسي وتنقل مباشر إلى السجل الأصلي.

## جديد v0.12.0 — دورة التدخل وقياس الأثر

تطورت التدخلات العلاجية والإثرائية داخل **التحصيل والنتائج** إلى دورة متابعة قابلة لقياس الأثر دون إنشاء وحدة مكررة. يمكن ربط كل إجراء بمقياس منظم: اسم المؤشر، الوحدة، اتجاه التحسن، خط الأساس، الهدف المسجل، النتيجة الفعلية، تاريخ القياس، ومصدر الهدف أو المعيار.

### قاعدة عدم اختراع المعايير

- لا يقترح التطبيق حدًا افتراضيًا جديدًا للتصنيف/الإتقان عند تسجيل نتيجة.
- يلزم توثيق مصدر الحد المستخدم في التقويم الجديد أو المعدل.
- يلزم توثيق مصدر الهدف أو المعيار عند تفعيل قياس أثر رقمي.
- نتيجة قياس الأثر حسابية فقط بالنسبة للهدف المسجل ولا تعني تلقائيًا حكمًا تربويًا وزاريًا.
- السجلات القديمة التي سبقت حقول المصدر لا تُعدّل ولا يُختلق لها مرجع؛ تظهر بوضوح بوصفها بلا مرجع موثق حتى تتم مراجعتها.

الحالات الحسابية الممكنة: **لم يُقَس بعد، حقق الهدف المسجل، تحسن ولم يبلغ الهدف، لم يحدث تغير، تراجع المؤشر**.

الجداول الجديدة تضاف تلقائيًا وبصورة محافظة على قاعدة v0.11:

```text
achievement_assessment_standards
achievement_action_metrics
```

لا يلزم SQL يدوي أو Secret جديد أو تعديل Google Drive.

## جديد v0.11.0 — البحث الشامل والتنقل السريع

تحول مربع **«ابحث في أعمال المادة...»** إلى محرك بحث فعلي يعمل على البيانات الأصلية نفسها دون جدول فهرسة موازٍ.

### نطاق البحث

- المعلمون والبيانات المهنية والسيرة الذاتية.
- الخطط ووحدات المنهج.
- التحصيل والتدخلات.
- الإشراف وإجراءات المتابعة.
- طلبات الملفات.
- الاجتماعات والقرارات.
- الفعاليات والمشاركون.
- الوثائق والمراجع.

### خصائص البحث

- تطبيع عربي للهمزات والتشكيل والتطويل.
- لا يرسل استعلامًا قبل إدخال حرفين على الأقل.
- تصفية حسب القسم والعام الدراسي.
- اختصار `Ctrl/Cmd + K`.
- ترتيب النتائج حسب الصلة ثم الحداثة.
- النتائج الفرعية مثل القرار أو وحدة المنهج تفتح السجل الأب المرتبط بها.
- يعمل في GitHub Pages بعقد معاينة مطابق.

```text
GET /api/search?q=...&section=all&academicYear=all&limit=40
```

المسار للقراءة فقط، ولا يبحث في نصوص التقارير المولدة لأنها بيانات مشتقة. لا يضيف v0.11.0 جدول SQLite أو Secret جديدًا ولا يغير إعداد Google Drive.

## جديد v0.10.0 — الأرشيف التاريخي وحزمة التسليم

أصبح تبويب **الأرشيف التاريخي** وحدة فعلية بدل placeholder. يكتشف الأعوام الدراسية تلقائيًا من السجلات الحالية ويجمع بيانات كل عام دون إنشاء نسخة موازية من البيانات.

### ما يعرضه الأرشيف

- التخطيط والمنهج.
- التحصيل والنتائج.
- الإشراف والمتابعة.
- الاجتماعات والقرارات.
- الفعاليات والتوثيق.
- الوثائق والمراجع.
- طلبات الملفات.
- المعلمون المرتبطون بسجلات العام.

### عقد القراءة

```text
GET /api/archive/years
GET /api/archive/year?academicYear=2026/2027
```

الأرشيف **قراءة فقط**، ولا يضيف جداول SQLite جديدة. زر «طباعة حزمة التسليم» يحول عرض العام إلى وثيقة A4 قابلة للطباعة من المتصفح.

ملاحظة دقة: لا يستخدم الأرشيف قائمة المعلمين الحالية بوصفها سجلًا تاريخيًا لطاقم كل سنة؛ بل يحسب المعلمين المرتبطين من علاقاتهم بالسجلات داخل العام المحدد.

## جديد v0.9.0 — مركز التقارير الرسمي

تحول تبويب **التقارير** من placeholder إلى وحدة تشغيلية كاملة تعتمد عقد تقرير موحدًا واحدًا، بدل بناء مولد مستقل لكل وحدة.

### أنواع التقارير

1. التقرير الشامل لأعمال القسم.
2. التقرير المهني للمعلم.
3. تقرير التخطيط ومتابعة المنهج.
4. تقرير التحصيل والنتائج.
5. تقرير الإشراف الفني والزيارات.
6. تقرير الاجتماعات والقرارات.
7. تقرير الفعاليات والتوثيق.

### خصائص مركز التقارير

- فلترة حسب العام الدراسي والفصل.
- اختيار المعلم عند إنشاء تقرير المعلم.
- مؤشرات مشتقة حتميًا من السجلات الأصلية.
- أقسام جدولية موحدة قابلة للتوسع دون تغيير شكل العقد.
- تقرير A4 قابل للطباعة مباشرة من المتصفح.
- إظهار السجلات الفارغة بوضوح بدل اختلاق أرقام بديلة.
- عدم استنتاج مهارات أو أحكام مهنية غير موجودة في البيانات.
- مسار API للقراءة فقط:

```text
GET /api/reports/official
```

مع معاملات:

```text
reportType
academicYear
term
teacherId   # لتقرير المعلم فقط
```

لا ينشئ v0.9.0 أي جدول SQLite جديد ولا يغير البيانات عند إنشاء التقرير.

## البنية التقنية

- **Frontend:** React 19 + TypeScript + Vite.
- **Backend:** FastAPI.
- **Database:** SQLite مع Foreign Keys وWAL.
- **Files:** محلي للتطوير أو Google Drive عبر OAuth ونطاق `drive.file`.
- **CI/CD:** GitHub Actions.
- **Preview:** GitHub Pages.

## التشغيل المحلي

### الخادم

```bash
python -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn server.main:app --reload --port 8000
```

### الواجهة

في طرفية ثانية:

```bash
npm install
npm run dev
```

ثم افتح:

```text
http://localhost:5173
```

للبناء الكامل:

```bash
npm run build
uvicorn server.main:app --port 8000
```

إذا كان مجلد `dist` موجودًا، يخدمه FastAPI تلقائيًا.

## Google Drive

الإعداد التفصيلي موجود في [`GOOGLE_DRIVE_SETUP_AR.md`](GOOGLE_DRIVE_SETUP_AR.md).

أهم متغيرات البيئة:

```text
GOOGLE_CLIENT_ID
GOOGLE_CLIENT_SECRET
GOOGLE_REDIRECT_URI
APP_ENCRYPTION_KEY
STORAGE_MODE
```

لا يحتاج v0.12.0 إلى سر جديد أو SQL يدوي أو تعديل إعداد OAuth؛ ترقية SQLite الإضافية تتم تلقائيًا.

## منهجية التطوير

- GitHub هو مصدر الحقيقة للكود.
- كل إصدار يُبنى فوق آخر `main` أخضر.
- لا تُسلَّم حزمة قبل اختبارها كـOverlay فوق النسخة المستقرة السابقة.
- تغييرات قاعدة البيانات، عند الحاجة، تكون إضافية ومحافظة على البيانات القديمة.
- لا يُعاد بناء منطق سبق أن أصبح مصدر حقيقة في وحدة أخرى.
- نجاح GitHub Actions شرط اعتماد الإصدار كنقطة استقرار رسمية.
- `README.md` في جذر المستودع هو صفحة التعريف الأساسية ويُحدث مع كل مرحلة كبيرة.

## حدود المشروع

إدارة المختبرات والأجهزة والمواد الكيميائية ليست ضمن نطاق «مرصد الإنجازات». التركيز هو الإدارة التربوية، المتابعة المهنية، التوثيق، التحصيل، التقارير، والذاكرة المؤسسية للقسم.
