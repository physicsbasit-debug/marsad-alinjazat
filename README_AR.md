# مرصد الإنجازات v0.5.0

نسخة أساس Full-Stack لمنصة المعلم الأول. الهدف هنا أن تكون الأعمال والطلبات والوثائق والفعاليات بيانات مترابطة، بينما يكون Google Drive هو مخزن الملفات عند تفعيل الربط.

## ما يعمل في v0.5.0

- واجهة عربية RTL حديثة بـ React + TypeScript.
- لوحة قيادة تركز على الأعمال التي تحتاج انتباهًا.
- ملفات المعلمين والسير الذاتية المهنية.
- قاعدة SQLite حقيقية.
- إنشاء طلب ملف وربط الطلب بالمعلم والمادة والصف والموعد.
- إنشاء رابط رفع سري للمعلم.
- صفحة رفع عامة لا تحتاج دخول لوحة الإدارة.
- التحقق من صلاحية رابط الرفع وحجم الملف ونوعه.
- وصول الملف إلى صندوق المراجعة وتحديث حالة الطلب تلقائيًا.
- اعتماد الطلب من مركز الطلبات.
- سجل فعاليات وتوثيق بصري.
- مكتبة وثائق مرتبطة بالملفات المستلمة.
- طبقة Google Drive OAuth حقيقية باستخدام نطاق `drive.file`.
- رفع Google Drive قابل للاستئناف resumable عند تشغيل `STORAGE_MODE=google_drive`.
- وضع تخزين محلي للتطوير قبل إدخال مفاتيح Google.




### جديد v0.5.0 — الاجتماعات والقرارات

- سجل اجتماعات فعلي بدل بطاقة تجريبية: عنوان الاجتماع ونوعه وتاريخه ووقته ومكانه وحالته.

- ربط الحضور مباشرة بمعلمي القسم مع إمكانية تحديث القائمة داخل المحضر.

## التشغيل المحلي

### 1) الخادم

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
# أنشئ ملف .env عند الحاجة إلى إعدادات التشغيل/Google Drive
uvicorn server.main:app --reload --port 8000
```

### 2) الواجهة

في طرفية ثانية:

```bash
npm install
npm run dev
```

افتح `http://localhost:5173` أثناء التطوير. رابط الرفع الذي ينشئه النظام سيشير لنفس عنوان الواجهة عبر `APP_PUBLIC_URL`.

بعد البناء:

```bash
npm run build
uvicorn server.main:app --port 8000
```

وسيقوم FastAPI بخدمة مجلد `dist` تلقائيًا إن كان موجودًا.

## ربط Google Drive

1. أنشئ OAuth Client من نوع **Web application** في Google Cloud.
2. فعّل Google Drive API.
3. ضع Redirect URI مطابقًا للقيمة في `.env`.
4. عبئ:
   - `GOOGLE_CLIENT_ID`
   - `GOOGLE_CLIENT_SECRET`
   - `GOOGLE_REDIRECT_URI`
   - `APP_ENCRYPTION_KEY`
5. شغل التطبيق.
6. اضغط بطاقة **Google Drive** في الشريط الجانبي.
7. مع `STORAGE_MODE=auto` ينتقل التخزين إلى Google Drive تلقائيًا بعد نجاح الربط. يمكن إجبار وضع معين عبر `local` أو `google_drive`.

التطبيق ينشئ مجلدًا باسم **مرصد الإنجازات** داخل Drive، ثم يبني تحته مجلد العام الدراسي وصندوق الوارد وطلب الملف.

## بنية البيانات

- `teachers`: ملفات المعلمين والسير الذاتية.
- `upload_requests`: طلبات الملفات وروابطها وحالاتها.
- `documents`: الملفات المستلمة وبيانات التخزين.
- `events`: الفعاليات والتوثيق.
- `meetings`: محاضر الاجتماعات.
- `meeting_attendees`: حضور الاجتماعات.
- `meeting_decisions`: القرارات والمسؤوليات ومواعيد المتابعة.
- `curriculum_plans`: خطط المنهج حسب المادة والصف والفصل.
- `curriculum_units`: وحدات الخطة ونسب الإنجاز والتأخير والمسؤوليات.
- `activities`: السجل الزمني للنشاطات.
- `settings`: إعدادات التطبيق وربط Drive المشفر.

## ملاحظات أمان

- لا توضع مفاتيح Google في الواجهة الأمامية.
- رمز OAuth refresh token يُخزن مشفرًا باستخدام `APP_ENCRYPTION_KEY`.
- رابط الرفع يحتوي token عشوائيًا ولا يمنح تصفح Google Drive.
- التطبيق يخزن hash للـtoken في SQLite، لا القيمة الأصلية.
- الحد الافتراضي للرفع 25 MB ويمكن تغييره من `.env`.
