هذه نسخة مرئية احتياطية من ملف GitHub Actions المخفي.

المسار الحقيقي الموجود أيضًا داخل الحزمة:
.github/workflows/quality-pages.yml

إذا كنت ترفع الملفات من هاتف أو مدير ملفات لا يُظهر المجلدات التي تبدأ بنقطة:
1) ارفع مجلد GITHUB_WORKFLOW_VISIBLE إن احتجت فقط لرؤية الملف.
2) داخل GitHub يجب أن يكون الملف النهائي في المسار:
   .github/workflows/quality-pages.yml
3) لا تحتفظ بنسختين عاملتين داخل .github/workflows.
