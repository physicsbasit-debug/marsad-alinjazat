مرصد الإنجازات — Phase S2-A Fix 2

سبب الإصلاح:
- بعض طرق الرفع من الهاتف/المتصفح تتجاهل الملفات التي تبدأ بنقطة، لذلك قد لا يصل .env.example إلى GitHub رغم وجود نسخته المرئية.

ما يفعله الإصلاح:
- يجعل حارس S1 يقبل .env.example كالمعتاد.
- إذا غاب .env.example، يستخدم ENV_EXAMPLE_VISIBLE.txt بوصفه fallback رسميًا مطابقًا لنفس عقد الأمان.
- إذا وُجد الملفان معًا، يجب أن يكون محتواهما متطابقًا حرفيًا.
- يمنع وجود SERVICE_ROLE أو Supabase Secret داخل قالب الواجهة.

لا يغير:
- React runtime.
- FastAPI/SQLite.
- مخطط S2-A.
- أي migration أو RLS أو بيانات.
